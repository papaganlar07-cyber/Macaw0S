# Quick Notes

Quick Notes, Macaw0S için eklenen küçük not aracıdır. Markdown dosyaları üretir ve kullanıcı notlarını `~/Notes/Macaw0S` altında tutar.

## Kullanım

```bash
quick-notes new "Fikirler"
quick-notes list
quick-notes show 20260814-120000-fikirler.md
quick-notes edit 20260814-120000-fikirler.md
quick-notes path
```

Bu araç ileride grafik not uygulamasına dönüşebilir; şimdilik günlük not alma akışını basit ve test edilebilir tutar.
