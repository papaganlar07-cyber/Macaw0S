# Aviary Settings

Aviary Settings, Macaw0S için hafif bir ayar aracıdır. İlk sürüm CLI tabanlıdır ve tema tercihi ile kullanıcı favorilerini yönetir.

## Kullanım

```bash
aviary-settings init
aviary-settings get theme
aviary-settings set theme macaw-dark
aviary-settings favorites list
aviary-settings favorites add Notes "vi ~/Notes/macaw.txt"
aviary-settings status
```

## Amaç

Bu araç ileride grafik ayarlar merkezine dönüşecek altyapıdır. Şimdilik günlük kullanımda tema ve launcher favorilerini bozmadan yönetmek için güvenli, test edilebilir bir temel sağlar.
