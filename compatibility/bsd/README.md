# BSD Native Compatibility

Macaw0S FreeBSD hedefinde ana uyumluluk stratejisi native FreeBSD paketleri, jail ve sanallaştırmadır.

- Native paketler: `freebsd-profile/packages.txt`
- Servis varsayılanları: `freebsd-profile/etc/rc.conf`
- Boot/kernel modülleri: `freebsd-profile/boot/loader.conf`
- Ağır iş izolasyonu: jail, bhyve, QEMU
